# Reset access PIN

PINs cannot be reset by users themselves — for now, this must be done by the system administrator.

---

## If you forgot your PIN

Contact the system administrator (ICM Newark secretariat) and provide:
- Your full name
- Your access profile (Clerk, Pastor, GA Leader, etc.)

The administrator will reset your PIN and let you know the new value.

---

## If your PIN is being rejected

Before requesting a reset, check the following:

**1. Are you clicking in the right field?**  
Make sure the cursor is in the PIN field before typing.

**2. Is Caps Lock on?**  
PINs are numeric, so Caps Lock shouldn't matter — but check anyway.

**3. Are you using the right PIN for your profile?**  
Each profile has a different PIN. If you have more than one profile, use the PIN that matches the access you want.

**4. Is the system responding?**  
Try reloading the page. If it keeps rejecting, it may be a connection issue.

If none of that works, contact the administrator.

---

## If you are the administrator

To reset a user's PIN:

1. Open the **Admin** panel
2. Go to **System users**
3. Find the user by name or profile
4. Click **Edit** and update the PIN
5. Save and communicate the new PIN to the user directly

> ⚠️ PINs are stored in the database. Choose values that aren't obvious — avoid sequences like `1111` or `1234`.
