# Registration System — ICM Newark

Welcome to the official documentation for the Igreja Cristã Maranata Newark registration system.

This site has everything you need to use the system confidently — whether you're a member registering for the first time, a clerk managing the waitlist, or an administrator setting up a new event.

---

## Where to start?

**First time here?**  
See the [First login](tutorials/first-login.md) tutorial — it takes less than 5 minutes.

**Want to register for an event?**  
The [Register a member](tutorials/register-member.md) tutorial walks you through the public portal step by step.

**Having trouble?**  
Check [Troubleshooting](troubleshooting/login-issues.md) — your answer is probably there.
