# Sistema de Inscripciones — ICM Newark

Bienvenido a la documentación oficial del sistema de inscripciones de la Iglesia Cristiana Maranata de Newark.

Este sitio reúne todo lo que necesitas para usar el sistema con confianza — ya seas un miembro haciendo su primera inscripción, un asistente administrando la lista de espera, o un administrador configurando un nuevo evento.

---

## ¿Por dónde empezar?

**¿Es tu primer acceso?**  
Consulta el tutorial [Primer acceso](tutorials/first-login.md) — son menos de 5 minutos.

**¿Quieres inscribirte en un evento?**  
El tutorial [Inscribir un miembro](tutorials/register-member.md) te guía paso a paso por el portal público.

**¿Tienes algún problema?**  
Consulta [Solución de problemas](troubleshooting/login-issues.md) — probablemente ya tiene respuesta.

Si no encuentras lo que necesitas aquí, contacta al equipo de coordinación del evento o al secretario responsable del sistema.
